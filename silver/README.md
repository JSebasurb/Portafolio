# 🥈 Silver — Fuente limpia y estructurada

Aquí se **trabaja**. Es el código fuente ordenado, separado por responsabilidad:

- `src/index.template.html` → estructura de la página (con placeholders `{{...}}`).
- `src/styles.css` → estilos.
- `src/app.js` → interactividad (pestañas, diseñador, WhatsApp).
- `data/site.json` → configuración editable: **número de WhatsApp**, título, descripción.
- `assets/` → imágenes ya optimizadas (WebP/JPG, ≤ 300 KB) que irán al sitio final.

Todo cambio se hace aquí; nunca en `gold/`.
